**CENTRAL CHALLENGE**

### How might we make public transit better?

#### Down 1 — What does “better transit” mean?

* How might we make public transit more reliable?
* How might we make public transit more affordable?
* How might we make public transit more accessible?
* How might we make public transit safer?
* How might we make public transit more comfortable?
* How might we make public transit easier to understand?
* How might we make public transit more convenient?
* How might we make public transit faster?
* How might we make public transit more environmentally sustainable?
* How might we make public transit more responsive to community needs?
* How might we make public transit more welcoming to new riders?
* How might we make public transit more useful for people who do not own cars?

#### Down 2 — What causes those problems?

**Reliability**

* How might we reduce delays?
* How might we make schedules more predictable?
* How might we improve connections between routes?
* How might we reduce missed transfers?
* How might we provide better information when disruptions occur?

**Affordability**

* How might we reduce the cost of using public transit?
* How might we make fares more equitable?
* How might we make transit financially accessible to low-income riders?
* How might we reduce the financial barriers to becoming a regular transit rider?

**Accessibility**

* How might we make transit easier to use for people with disabilities?
* How might we make transit information more accessible?
* How might we accommodate different mobility needs?
* How might we make stops and stations easier to navigate?
* How might we make transit more accessible to people with sensory differences?

**Safety**

* How might we make riders feel safer waiting for transit?
* How might we make riders feel safer while riding transit?
* How might we improve responses to harassment?
* How might we improve lighting and visibility around transit stops?
* How might we make transit safer without making it feel hostile?

**Convenience**

* How might we reduce the amount of time people spend waiting?
* How might we make routes easier to understand?
* How might we make payment easier?
* How might we make transfers easier?
* How might we make transit fit more naturally into people's daily routines?

#### Down 3 — Specific design opportunities

* How might we provide riders with more accurate real-time information?
* How might we help riders recover from unexpected delays?
* How might we design better transfer points?
* How might we make bus stops more comfortable while people wait?
* How might we make transit information understandable without prior knowledge?
* How might we help people determine the best route for their needs?
* How might we make transit usable for people carrying groceries, luggage, or mobility equipment?
* How might we make transit easier to use at night?
* How might we improve communication between transit agencies and riders?
* How might we allow riders to communicate problems with routes or stops?
* How might we encourage people who currently drive to try transit?
* How might we make transit more appealing for occasional riders?
* How might we design transit around people's actual travel patterns?
* How might we reduce uncertainty throughout the transit journey?

* How might we reduce people's dependence on private vehicles?
* How might we make transportation more equitable?
* How might we make it easier for people to participate in their communities?
* How might we make transportation work for people with different abilities?
* How might we connect people with employment, education, healthcare, and recreation?

* How might we make it easier for people to access community resources?
* How might we reduce isolation caused by transportation barriers?
* How might we connect neighbourhoods more effectively?
* How might we make cities easier to navigate without a car?
* How might we ensure transportation reflects the needs of diverse communities?

### Information

* How might we make transit information easier to find?
* How might we make transit information easier to understand?
* How might we make information trustworthy?
* How might we personalize transit information without compromising privacy?
* How might we communicate disruptions effectively?

### Infrastructure

* How might we improve bus stops?
* How might we make transit stops comfortable in bad weather?
* How might we improve accessibility at transit stops?
* How might we make transit infrastructure safer?
* How might we design infrastructure around how people actually wait and move?

### Riders

* How might we better understand why people choose not to use transit?
* How might we design for occasional riders?
* How might we design for people who depend on transit every day?
* How might we involve riders in transit decisions?
* How might we give marginalized communities greater influence over transit design?

### Transit workers

* How might we improve conditions for transit operators?
* How might we reduce stress for transit workers?
* How might we improve communication between operators and riders?
* How might we give transit workers better tools to respond to problems?

### System

* How might we make transit agencies more responsive?
* How might we improve coordination between transit services?
* How might we allocate transit resources more effectively?
* How might we make transit planning more evidence-based?
* How might we involve communities in deciding where transit should go?
